# Syncfusion® Blazor DOCX Editor – Performance Benchmark Sample

## Introduction

This sample demonstrates performance benchmarking scenarios using the Syncfusion® Blazor DOCX Editor. It enables users to measure key document processing operations using predefined benchmark documents.

## Project Features

- Load predefined benchmark documents (50, 100, 200, and 500 pages).
- Measure component initialization performance.
- Measure document opening performance.
- Measure DOCX download performance.
- Measure RTF, HTML, and PDF export performance.
- View benchmark metrics directly within the application.

## How to Run the Sample

This sample consists of a Blazor client application and an ASP.NET Core backend service. Both applications must be running.

### 1. Start the ASP.NET Core backend

Navigate to the server project directory and run:

```bash
dotnet run
```

### 2. Restore dependencies

Navigate to the Blazor project directory and run:

```bash
dotnet restore
```

### 3. Start the Blazor application

```bash
dotnet run
```

### 4. Open the application

Open the URL displayed in the terminal after the application starts.
